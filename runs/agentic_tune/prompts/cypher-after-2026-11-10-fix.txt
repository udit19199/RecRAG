
Task: Generate one read-only Cypher statement for a Neo4j 5 graph database from a user input.

Schema:
{schema}

Examples:
{examples}

Rules:
- Use only node labels, relationship types, and properties listed in the schema.
- Every extracted entity also has the label __Entity__ with a name and optional aliases.
- Match names case-insensitively: compare toLower(n.name), and each alias in coalesce(n.aliases, []), with a lowercase string.
- Write every string in double quotes. Names are stored with both ' and ’ apostrophes, so match words that contain no apostrophe: for Ja'Marr Chase, "marr" and "chase".
- To find a headline or long title, match two or three distinctive lowercase words from it, each with its own CONTAINS; never the whole title.
- Put each WHERE directly after the MATCH it filters. A WHERE after OPTIONAL MATCH filters only that OPTIONAL MATCH.
- To find passages, match entities by name and follow FROM_CHUNK to the Chunk; never filter Chunk.text with CONTAINS.
- Return at most one passage per row; never collect() passage text.
- Write alternative relationship types as [:A|B].
- Return names and short properties, never embedding, and end with LIMIT 10 or less.

Input:
{query_text}

Return only the Cypher statement, with no triple backticks or other text.

Cypher query:


=== EXAMPLES (news graph) ===
USER INPUT: 'What does the TechCrunch article on the Google antitrust suit say?' QUERY: MATCH (a:Article)-[:PUBLISHED_BY]->(p:Publisher) WHERE toLower(p.name) CONTAINS "techcrunch" AND toLower(a.name) CONTAINS "google" AND toLower(a.name) CONTAINS "antitrust" MATCH (a)-[:FROM_CHUNK]->(c:Chunk) RETURN a.name AS article, p.name AS publisher, c.text AS passage LIMIT 10
USER INPUT: 'What is Ja'Marr Chase connected to?' QUERY: MATCH (n:__Entity__)-[r]-(m:__Entity__) WHERE toLower(n.name) CONTAINS "marr" AND toLower(n.name) CONTAINS "chase" RETURN n.name AS entity, type(r) AS relationship, m.name AS related LIMIT 10
USER INPUT: 'Which passages mention Sam Altman?' QUERY: MATCH (n:Person)-[:FROM_CHUNK]->(c:Chunk)-[:FROM_DOCUMENT]->(d:Document) WHERE (toLower(n.name) CONTAINS "sam altman" OR any(alias IN coalesce(n.aliases, []) WHERE toLower(alias) CONTAINS "sam altman")) RETURN n.name AS person, d.title AS page, c.text AS passage LIMIT 10

Row size cap (characters): 2000
