# RecRAG documentation

RecRAG compares retrieval architectures on multi-hop questions. The current implementation studies GraphRAG.
The router study compares that family with Classical RAG and Agentic RAG.

## Research areas

- [Router study](router/router-study.md) collects routing and router-evaluation
  ideas, including the Jev and GPT comparison.
- [Classical RAG](rag/classical-rag.md) describes passage retrieval without a
  graph.
- [GraphRAG](graphrag/construction.md) describes graph construction and
  retrieval.
- [Agentic RAG](agenticrag/agentic-rag.md) describes model-directed search.
