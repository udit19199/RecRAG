# Agentic RAG

Agentic RAG lets a model choose search tools and search steps while it answers. The workflow must record tool calls, failed calls, retries, and loops.

RecRAG does not have a separate Agentic RAG architecture yet.
The current `agentic` retrieval method is one GraphRAG candidate, so it stays documented under `graphrag/`.

The wider comparison will treat Agentic RAG as a separate architecture family.
